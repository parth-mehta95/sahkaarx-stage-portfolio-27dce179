# Implement Regularization in Capstone Model

## Task Brief
Apply L1/L2 regularization and early stopping to your capstone model, document findings in Git commits, and compare performance metrics.

## Scenario
Your ML team needs to reduce overfitting in production models. Extend your capstone repo with regularization strategies and document findings.

## Deliverables
- Regularization notebook with L1/L2 and early stopping
- Performance comparison plots showing regularization impact
- Git commits with clear regularization strategy messages

## Success Criteria
- Validation loss gap reduced by at least 15% vs unregularized model
- Early stopping checkpoint saved and documented
- Commit history shows regularization decisions and results
- Overfitting & Underfitting: Regularization reduces validation loss gap vs baseline
- Overfitting & Underfitting: Early stopping prevents overfitting with clear stopping point
- Overfitting & Underfitting: Git commits document regularization strategy and results
